# Strength & Fitness Android App

This is an Android WebView wrapper around the Strength & Fitness HTML app. The HTML is bundled inside the APK, so the workout tracker works offline and does not depend on a hosted website.

## Build

Open this folder in Android Studio and run **Build > Build APK(s)**. The debug APK will be at:

`app/build/outputs/apk/debug/app-debug.apk`

The included GitHub Actions workflow can also build the APK automatically after the project is pushed to a GitHub repository.
